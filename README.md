# BuyDUCK

Первый локальный кликабельный прототип магазина обуви, одежды и аксессуаров для Украины.

## Запуск

https://rostislav594.github.io/BayDUCK/

Админ-панель: https://rostislav594.github.io/BayDUCK/admin.html

```powershell
npm run dev
```

Откройте http://127.0.0.1:5173 . Для другого порта: `$env:PORT=5174; npm run dev`.

Для просмотра со смартфона в одной локальной сети с компьютером:

```powershell
npm run dev:lan
```

Этот режим запускается на порту 5174 и принимает подключения из локальной сети. Откройте на телефоне адрес `BuyDUCK network preview`, который напечатает сервер. `127.0.0.1` на смартфоне указывает на сам смартфон. Компьютер должен оставаться включённым, а сервер — запущенным. Подключения могут ограничиваться брандмауэром Windows или изоляцией клиентов в Wi-Fi. Обычный `npm run dev` по-прежнему доступен только на компьютере; публикации в интернете нет.

```powershell
npm test
npm run build
```

Сборка копирует статические файлы в `dist/`. Открывать прототип следует через HTTP-сервер: ES-модули не рассчитаны на открытие `index.html` по `file://`.

## Что работает

- Админ-панель-заглушка: отдельная страница `admin.html`, локально — http://127.0.0.1:5173/admin . На витрине ссылки нет, входа нет. Разделы: «Товари» (демо-каталог только для чтения), «Замовлення» (все заказы с доставкой Новою Поштою), «OLX» (заглушка до получения ключей API), «Активність» (посещения, просмотры страниц и товаров, корзина, оформления, демо-заказы, сумма, конверсия, график по дням, воронка, популярные товары, поисковые запросы; периоды: сегодня / 7 / 30 дней / всё время). Ничего не сохраняет, кроме общего выбора языка. Языки админки — только украинский и русский; если на витрине выбран английский, админка открывается на украинском. В левом верхнем углу — неактивная надпись «Admin» без ссылки на магазин.
- Плашка «Демо» над шапкой на всех страницах и трёх языках: товары и цены условные, заказы не отправляются. Убрать перед реальным запуском магазина.
- Главная с фирменным логотипом, карточками товаров и переходами в каталог.
- Desktop и mobile используют общую композицию: карточки разного размера и на разной высоте под категориями, асимметричные интерактивные иллюстрации вокруг. На desktop карточки крупнее; на узких телефонах размещаются в два ряда. На desktop пустые места первого экрана заполнены дополнительными карточками обуви: с 1001 px — две в промежутках нижнего ряда, с 1101 px — ещё две по бокам от логотипа (всего 7). У каждой карточки свой размер и угол наклона. В каталоге всего пять моделей обуви, поэтому Air Motion и Court Essential повторяются, но не рядом со своими копиями. Контент страницы на desktop доходит до правого края: отступ `#app` делается только слева, под боковую панель. С 1280 px первый экран повторяет раскладку, которую владелец расставил вручную на 1912 px (сохранена в `artifacts/hero-layout.json`): верхние карточки, песочная пара и портфель держат свою долю поля между колонкой логотипа и краем, нижний ряд и кроссовки под категориями — долю ширины, высокий кроссовок — фиксированный зазор от категорий. На 1280–1439 px несколько элементов слегка сдвинуты, чтобы ничего не пересекалось; на 1101–1279 px остаётся прежняя раскладка. Траектории полёта считаются от текущих позиций, поэтому падение сверху, петли и 1,5 с сохраняются. Прозрачный блок с категориями больше не перекрывает нижние карточки: их снова можно открыть мышкой.
- Редактор раскладки для владельца (только локальный сервер): http://127.0.0.1:5173/?edit-layout#home. Карточки и мультяшную одежду можно перетаскивать, наклонять и менять размер; «Сохранить» пишет `artifacts/hero-layout.json` и копию с датой (папка не в git). Без `?edit-layout` магазин не меняется; на GitHub Pages сохранение не работает, есть «Скопировать JSON». Код: `src/layout-editor.js`, запись — `/__layout` в `scripts/serve.mjs`.
- На мобильных экранах низкий мультяшный кроссовок находится сразу под «Кросівки», мятная пара — левее «Усе», высокий — правее «Аксесуари». На узких телефонах боковые иллюстрации переходят чуть ниже категорий. Три компактные карточки Court Essential, Retro Runner 02 и Air Motion расположены ниже: один ряд на широких мобильных экранах, два ряда на узких.
- Интерактивные мультяшные низкий кроссовок, высокий баскетбольный кроссовок, портфель и две дополнительные пары (песочно-терракотовая и мятно-серая) на главной: общая анимация полёта к корзине с коротким синим хвостом кометы. Все предметы долетают до корзины за одинаковые 1,5 секунды независимо от длины пути. Корзина стоит вертикально и не поворачивается; предмет подлетает сверху и опускается в неё строго вертикально. Предметы, которые стартуют ниже корзины (низкий и высокий кроссовки, мятная пара), по пути делают «мёртвую петлю» с полным оборотом, а петля подбирается так, чтобы поместиться в первый экран и не задеть корзину; предмет остаётся скрытым до обновления страницы, перехода на другую страницу или переключения вкладки. Быстрые нажатия ставятся в очередь, Enter/Space поддержаны, при `prefers-reduced-motion` используется смена прозрачности без хвоста. Старые отдельные анимации удалены.
- Мультяшная корзина перед B в главном логотипе, стоящая днищем вниз (исходный PNG нарисован на боку и повёрнут на −90° в CSS) и выполненная в стиле портфеля и худи; исходный PNG маскота и надписи сохранён. Низкий кроссовок находится ниже категорий, под «Усе» и немного левее кнопки; высокий — справа внизу. Подвал содержит бренд и помощь без дублирующего списка категорий.
- Каталог, категории, разделы для женщин и мужчин (включая unisex), скидки, поиск, сортировка по цене.
- Карточка товара, выбор размера и добавление в корзину.
- Избранное, изменение количества и удаление из корзины; данные хранятся в `localStorage` браузера.
- Личный кабинет (демо, данные только в этом браузере): регистрация и вход по почте и паролю, «Запомнить меня» (иначе сессия живёт до закрытия вкладки), показ пароля, экран восстановления пароля (письма в прототипе не отправляются), блокировка входа на минуту после 5 неверных попыток. Страница `#account`: история заказов, профиль и данные доставки, смена пароля, выход, удаление аккаунта с подтверждением паролем. Пароли хранятся только как хеш PBKDF2-SHA256 (на http-адресах в локальной сети без WebCrypto — запасной итеративный SHA-256). Быстрая покупка без регистрации осталась: гость оформляет заказ как раньше, личные данные не сохраняются. Вошедшему покупателю данные подставляются в форму, заказ получает номер и сохраняется в кабинете, данные доставки можно сохранить в профиль. Иконка кабинета есть в шапке, боковой панели и мобильном меню. Точка замены на сервер Railway — `createAccountStore()` в `src/accounts.js`.
- Демонстрационный сценарий оформления с обязательными полями. Личные данные не отправляются и не сохраняются. При завершении корзина сохраняется, чтобы можно было продолжить проверку.
- Украинский по умолчанию, русский и английский. Выбранный язык сохраняется в браузере.
- Мобильное меню, адаптивная сетка, клавиатурный фокус и нативные модальные диалоги с Escape.

- `src/i18n.js` — три языковых словаря.
- `src/catalog.js` — каталог владельца (демо в `localStorage`, ключ `buyduck:catalog`): проверка формы, сохранение, статусы «На сайті / Прихований / Продано», ссылка на OLX, сжатие фото и текст объявления для OLX; заменяет содержимое общего массива `products`, поэтому витрина видит товары владельца без других изменений. `src/admin-products.js` — вкладка «Товари» админки. `tests/catalog.test.mjs` проверяет каталог.

- `src/analytics.js` — журнал действий посетителей и подсчёт статистики для вкладки «Активність»; `tests/analytics.test.mjs` проверяет визиты, воронку и периоды.
- `docs/` — планы интеграции с OLX: ручная связка, черновик заявки на API и инструкция по получению ключей (`docs/olx-api-access-guide.md`).
- `src/model.js` — фильтры, проверка сохранённых данных и расчёты корзины.
- `src/accounts.js` — демо-хранилище аккаунтов: регистрация, вход, сессия, профиль, смена пароля, история заказов, удаление; `tests/accounts.test.mjs` проверяет его в Node.
- `tests/browser-account.js` — браузерная проверка кабинета и быстрой покупки (Playwright MCP, аналогично `tests/browser-smoke.js`).
- `src/hero-basket.js` — декоративная корзина у логотипа на главной: по нажатию плавно уезжает за букву B; `tests/browser-basket-finale.js` проверяет её в браузере (Playwright MCP).

- `tests/model.test.mjs` — проверки логики и согласованности локализации/каталога.
- `tests/browser-clothing-flight.js` — браузерная проверка общего полёта, очереди, клавиатуры, прерываний и режима уменьшенного движения (Playwright MCP, аналогично `tests/browser-smoke.js`).

## Границы прототипа

Это не запущенный магазин. Ассортимент, названия моделей, цены, размеры, скидки и изображения демонстрационные. Backend, настоящая авторизация, реальные остатки, доставка, оплата и отправка заказов не подключены: это кликабельный прототип, сервер на Railway и внешние сервисы подключаются позже (см. `PROJECT.md`). Доставка и возвраты открывают информационные окна с текущим статусом, а не утверждённые условия магазина. Внешняя публикация не настроена.

Git remote `origin`: `https://github.com/Rostislav594/BayDUCK.git`. Основная ветка — `main`, отслеживающая `origin/main`. Существующий начальный коммит с README сохранён в истории.

## Подача полёта: обход препятствий и хвост кометы — 21 октября 2026

- Вращение корзины стало равномерным на всём обороте и повороте ручкой вверх. Между 360° и 450° нет отдельного замедления; вертикальное положение удерживается только для приёма предмета. Возврат на бок имеет ту же угловую скорость.
- `src/flight-path.js` строит обход препятствий по текущим границам логотипа, поиска, категорий, карточек, подписей и других иллюстраций. Углы скругляются с повторной проверкой зазоров. Финальный участок проходит вертикально сверху вниз; скорость движения по длине пути равномерная. В свободных местах предмет крупнее, в узких проходах уменьшается с учётом поворота изображения.
