# BayDUCK

Первый локальный кликабельный прототип магазина обуви, одежды и аксессуаров для Украины.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов не требуется: проект не имеет сторонних зависимостей.

```powershell
npm run dev
```

Откройте http://127.0.0.1:5173 . Для другого порта: `$env:PORT=5174; npm run dev`.

Для просмотра со смартфона в одной локальной сети с компьютером:

```powershell
npm run dev:lan
```

Этот режим запускается на порту 5174 и принимает подключения из локальной сети. Откройте на телефоне адрес `BayDUCK network preview`, который напечатает сервер. `127.0.0.1` на смартфоне указывает на сам смартфон. Компьютер должен оставаться включённым, а сервер — запущенным. Подключения могут ограничиваться брандмауэром Windows или изоляцией клиентов в Wi-Fi. Обычный `npm run dev` по-прежнему доступен только на компьютере; публикации в интернете нет.

```powershell
npm test
npm run build
```

Сборка копирует статические файлы в `dist/`. Открывать прототип следует через HTTP-сервер: ES-модули не рассчитаны на открытие `index.html` по `file://`.

## Что работает

- Плашка «Демо» над шапкой на всех страницах и трёх языках: товары и цены условные, заказы не отправляются. Убрать перед реальным запуском магазина.
- Главная с фирменным логотипом, карточками товаров и переходами в каталог.
- Интерактивные мультяшные кроссовок, худи, кепка и носки на главной: короткие анимации по нажатию, управление с клавиатуры, спокойная обратная связь при `prefers-reduced-motion`.
- Каталог, категории, разделы для женщин и мужчин (включая unisex), скидки, поиск, сортировка по цене.
- Карточка товара, выбор размера и добавление в корзину.
- Избранное, изменение количества и удаление из корзины; данные хранятся в `localStorage` браузера.
- Демонстрационный сценарий оформления с обязательными полями. Личные данные не отправляются и не сохраняются. При завершении корзина сохраняется, чтобы можно было продолжить проверку.
- Украинский по умолчанию, русский и английский. Выбранный язык сохраняется в браузере.
- Мобильное меню, адаптивная сетка, клавиатурный фокус и нативные модальные диалоги с Escape.

## Структура

- `AGENTS.md` — правила работы агентов и ссылки на проектные документы.
- `DESIGN.md` — визуальный ориентир.
- `PROJECT.md` — требования и статус проекта.
- `src/app.js` — интерфейс и сценарии взаимодействия.
- `src/styles.css` — стили и адаптивность.
- `src/i18n.js` — три языковых словаря.
- `src/data.js` — демонстрационный каталог.
- `src/model.js` — фильтры, проверка сохранённых данных и расчёты корзины.
- `src/playful-clothes.js`, `src/playful-clothes.css` — интерактивные иллюстрации, анимации и их адаптивное размещение.
- `assets/playful/` — четыре PNG с прозрачным фоном и `PROMPTS.md` с промптами генерации через imagegen.
- `assets/branding/` — версии маскота и логотипа, промпты генерации.
- `assets/products/` — локальные фотографии и `SOURCES.md` с источниками.
- `tests/model.test.mjs` — проверки логики и согласованности локализации/каталога.

## Границы прототипа

Это не запущенный магазин. Ассортимент, названия моделей, цены, размеры, скидки и изображения демонстрационные. Backend, авторизация, реальные остатки, доставка, оплата и отправка заказов не подключены. Доставка и возвраты открывают информационные окна с текущим статусом, а не утверждённые условия магазина. Внешняя публикация не настроена.

Git remote `origin`: `https://github.com/Rostislav594/BayDUCK.git`. Основная ветка — `main`, отслеживающая `origin/main`. Существующий начальный коммит с README сохранён в истории.

Сценарий браузерной проверки сохранён в `tests/browser-smoke.js`: это функция для инструмента Playwright MCP `browser_run_code_unsafe` с аргументом `filename`, а не тест команды `npm test`.
