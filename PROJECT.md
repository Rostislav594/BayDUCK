# BayDUCK

## Подтверждённые требования

- Название магазина: **BayDUCK**.
- Интернет-магазин преимущественно обуви, а также одежды и аксессуаров.
- Рынок: Украина.
- Язык по умолчанию: украинский (`uk`).
- Дополнительные языки: русский (`ru`) и английский (`en`).
- Необходим переключатель языков. Локализацию учитывать с начала разработки: тексты интерфейса хранить отдельно от компонентов, предусмотреть переводы контента товаров.
- Валюта витрины: гривна (`UAH`), исходя из рынка Украины.

## Визуальное направление

Основной ориентир — `DESIGN.md`: светлая основа, крупные фотографии товаров, округлые карточки, мягкие тени, фиолетовый акцент `#5433eb`.

Фирменный персонаж: утка в кроссовках, кепке задом наперёд и клетчатой рубашке.

Первый концепт персонажа: `assets/branding/bayduck-mascot-concept-v1.png`. Пользователю понравился маскот; его внешний вид сохраняем при дальнейшей разработке.

По уточнению пользователя главный акцент логотипа — надпись **BayDUCK**. Утка сидит на букве **D**, сохраняя объём, полную фигуру, одежду и заметные кроссовки.

Второй концепт: `assets/branding/bayduck-wordmark-mascot-v2.png` — крупная надпись и сидящий на D персонаж, PNG с прозрачным фоном. Концепт ожидает обратной связи; компактная версия знака ещё не разработана.

На главной логотип перенесён из левого угла шапки в центр первого экрана над поиском, заменив слоган и описание. В каталоге компактный логотип в шапке сохранён как переход на главную.

На desktop основной контейнер имеет симметричные боковые отступы по 68px: левый отступ резервирует место для навигационной панели, правый сохраняет центрирование сайта относительно окна. На мобильных экранах оба отступа убираются вместе с панелью.

По отдельному запросу пользователя в свободные места первого экрана добавлены мультяшные элементы одежды в стиле маскота: кроссовок, худи, кепка и носки. Они запускают разные короткие анимации по нажатию; постоянного движения нет. Это согласованное расширение исходного `DESIGN.md`, в котором иллюстрации не предполагались. На мобильных и планшетных экранах иллюстрации также разбросаны по свободным местам: худи и кепка сверху по краям логотипа, кроссовок и носки — ниже на разной высоте. Поддержаны клавиатура, три языка и `prefers-reduced-motion`.

Исходные PNG и промпты генерации: `assets/playful/`. Разметка и анимации: `src/playful-clothes.js`; адаптивное размещение: `src/playful-clothes.css`.

## Текущее состояние

Создан локальный кликабельный прототип на HTML/CSS/JavaScript (ES-модули), без сторонних зависимостей. Запуск и ограничения описаны в `README.md`; инструкции для дальнейшей работы — в `AGENTS.md`.

Доступны главная, каталог, поиск, фильтры, сортировка, карточка товара с размерами, избранное, корзина и демонстрационное оформление. Языки `uk` / `ru` / `en`; язык, избранное и корзина сохраняются в браузере.

Git remote `origin`: `https://github.com/Rostislav594/BayDUCK.git`. Основная рабочая ветка — `main`, отслеживающая `origin/main`. Начальный коммит удалённого репозитория с README сохранён в истории; изменения прототипа коммитятся поверх него. Коммиты и отправка выполняются только по явному запросу пользователя.

Реальный ассортимент, backend, авторизация, остатки, оплата, доставка и отправка заказов ещё не определены и не подключены. Данные, цены и фотографии каталога демонстрационные.
