# BayDUCK × OLX — вариант В: ручная связка

Статус: предварительное решение пользователя от 2026-10-21, ещё не реализовано.
Почему не API: см. раздел «Интеграция с OLX» в [PROJECT.md](../PROJECT.md). Если доступ к OLX Partner API появится позже, этот вариант остаётся основой: меняется только способ переноса данных.

## Идея в одном абзаце

Главный каталог живёт **на сайте BayDUCK**. Клиент заводит товар один раз в закрытой панели сайта. Сайт сам готовит всё для объявления на OLX: заголовок, описание, характеристики и фото. Клиент переносит это в OLX вручную, примерно за минуту, и вставляет ссылку на готовое объявление обратно на сайт. Покупатель на сайте видит кнопку «Купити на OLX» и может оформить заказ через OLX Доставку с защитой сделки. Автоматического обмена данными с OLX нет: никакого API и никакого сбора данных со страниц OLX.

## Кто что видит

| | Покупатель (витрина) | Клиент-продавец (панель `/admin`) |
|---|---|---|
| Доступ | открыт всем | только по логину |
| Товары | каталог, карточка, фото, размеры, цена | список, добавление, редактирование, статусы |
| OLX | кнопка «Купити на OLX» в карточке | «Підготувати для OLX», поле ссылки, сверка |

## Сценарии

### 1. Первичный перенос товаров с OLX (один раз)

1. Клиент открывает в панели «Додати товар».
2. Копирует из своего объявления на OLX название, описание и цену. Загружает фото с телефона или компьютера. Если оригиналы фото у клиента есть, лучше брать их: фото с OLX сжаты и могут быть с водяными знаками.
3. Вставляет ссылку на объявление OLX в поле «Оголошення на OLX».
4. Выбирает категорию, пол, размеры в наличии и бренд.
5. Нажимает «Зберегти»: товар появляется на сайте уже с кнопкой «Купити на OLX».

Чтобы перенос шёл быстрее, в форме будут подсказки к полям, автосохранение черновика и «Зберегти і додати наступний».

### 2. Новый товар: сначала на сайте, потом на OLX

1. «Додати товар» → заполнить карточку (как выше, без ссылки).
2. Кнопка **«Підготувати для OLX»** открывает окно:
   - **Заголовок** собирается из бренда, модели, типа, цвета и размеров (например, «Кросівки BayDUCK Court Essential білі, р. 36–45»). Видна длина в символах.
   - **Опис** — готовый текст по шаблону: описание товара, затем список размеров в наличии, затем состояние, затем условия магазина (доставка, обмен) и ссылка на сайт.
   - **Рубрика OLX** — подсказка пути: например, «Мода і стиль → Взуття → …».
   - **Характеристики**: размер, бренд, состояние, колір — в том виде, как их просит форма OLX.
   - **Ціна** в UAH.
   - **Фото**: кнопка «Завантажити всі фото» скачивает их пакетом, уже уменьшенными до разумного размера.
   - У каждого поля — кнопка «Копіювати».
3. Клиент нажимает «Відкрити OLX», подаёт объявление, копируя поля по одному.
4. Вставляет ссылку на опубликованное объявление в карточку товара → статус меняется на **«На OLX»**.

### 3. Изменение цены или наличия

- Клиент меняет цену или размеры на сайте. Если у товара есть ссылка на OLX, панель показывает напоминание: «Оновіть ціну на OLX» со ссылкой на объявление и новым значением для копирования.
- Пока клиент не нажмёт «Оновлено на OLX», товар висит в списке **«Потрібно оновити на OLX»**.

### 4. Продажа

- **Продано на OLX** → клиент отмечает в панели «Продано» или уменьшает остаток размера. Товар скрывается с сайта или помечается «Немає в наявності».
- **Продано через сайт** (если на сайте останется своё оформление заказа) → панель напоминает деактивировать объявление на OLX.

### 5. Сверка (раз в неделю)

Страница **«Звірка з OLX»** в панели:
- товары без ссылки на OLX;
- товары, ждущие обновления на OLX;
- товары «Продано», у которых объявление, возможно, ещё активно;
- для каждого товара — дата последней проверки и кнопка «Перевірено».

Проверку самих объявлений клиент делает глазами в своём кабинете OLX: сайт OLX сам не опрашивает.

## Что видит покупатель

- В карточке товара — основная кнопка **«Купити на OLX»**: объявление открывается в новой вкладке, где покупатель оформляет OLX Доставку.
- Если у товара нет ссылки на OLX, кнопки нет: работает запасной способ связи (см. открытые вопросы).
- Тексты кнопок и подписей — на трёх языках сайта. Объявление на OLX — на украинском.

## Данные товара (что добавится к текущему `src/data.js`)

| Поле | Зачем |
|---|---|
| `olxUrl` | ссылка на объявление; включает кнопку «Купити на OLX» |
| `status` | `draft` / `active` / `sold` / `hidden` |
| `olxStatus` | `none` / `published` / `needs-update` |
| `olxCheckedAt` | дата последней сверки |
| `condition` | `new` / `used` — OLX спрашивает состояние |
| `stock` по размерам | какие размеры в наличии и сколько |
| `description` на `uk` (обязательно), `ru`/`en` (по желанию, иначе показывать `uk`) | карточка товара и текст для OLX |
| несколько `images` | галерея и пакет фото для OLX |

Шаблон заголовка и описания для OLX, а также соответствие категорий BayDUCK рубрикам OLX хранятся в настройках, а не в коде каждого товара.

## Что для этого нужно технически

Витрину и генератор текста для OLX можно сделать на текущем статическом прототипе. **Панели управления нужно где-то хранить товары и фото**, а у GitHub Pages такого хранилища нет. Варианты, от простого к основательному:

1. **Каталог в репозитории + готовая панель-редактор** (класс Git-based CMS, например Decap CMS). Изменения сохраняются коммитом в GitHub, сайт обновляется сам. Бесплатно и без своего сервера, но вход в панель нужно настроить через GitHub, а фото хранятся в репозитории.
2. **Готовый «headless» сервис каталога или таблица** (Google Sheets, Airtable или подобное) как источник товаров. Панель — их интерфейс. Нет своего сервера, но интерфейс чужой и есть лимиты сервисов.
3. **Свой небольшой сервер с базой и хранилищем фото.** Полный контроль, своя панель в стиле BayDUCK, понадобится и для своего оформления заказов. Это платный хостинг (Railway и подобные).

Выбор зависит от ответов на открытые вопросы ниже. Ни один из вариантов не мешает позже подключить OLX Partner API.

## Открытые вопросы к клиенту

1. Сколько товаров сейчас на OLX и сколько новых в неделю? Это определяет, насколько удобным должен быть ручной перенос.
2. Нужно ли на сайте своё оформление заказа, или покупка идёт только через OLX? Запасной контакт: Telegram, Viber, телефон?
3. Кто будет вести панель: один человек или несколько?
4. Товары новые, б/у или и те и другие?
5. Есть ли у клиента оригиналы фото, или фото только на OLX?
6. Нужны ли описания товаров на `ru`/`en`, или достаточно украинского с автоматическим показом на всех языках?

## Чего здесь сознательно нет

- Автоматического чтения страниц OLX и публикации туда: это нарушает правила OLX.
- Хранения логина и пароля клиента от OLX на сайте.
- Точных лимитов OLX (длина заголовка и описания, число фото, бесплатные лимиты по рубрикам): их показывает сама форма подачи на OLX и раздел помощи. Сверим на первом реальном объявлении и зашьём в генератор.
