# BuyDUCK — как покупатель оформляет заказ

Статус: ответы клиента получены 2026-10-28 (раздел в конце); сценарий реализован в прототипе как демо в браузере (`src/orders.js`, корзина, вкладка «Замовлення» в админке).
Связано: [olx-manual-flow.md](./olx-manual-flow.md) (каталог и объявления на OLX), раздел «Стратегия разработки и хостинг» в [PROJECT.md](../PROJECT.md).

## Два способа покупки

| | **Нова Пошта — заказ на сайте** | **Безпечна угода OLX** |
|---|---|---|
| Где оформляется | в корзине BuyDUCK | на странице объявления OLX |
| Кто принимает деньги | продавец: при получении (наложенный платёж) или предоплатой | OLX: держит деньги, пока покупатель не заберёт посылку |
| Сколько товаров за раз | вся корзина одним заказом | каждый товар — отдельное объявление и отдельная покупка |
| Что видит сайт | весь заказ, статусы, номер ТТН | только переход на OLX; саму покупку сайт не видит |
| Защита покупателя | доверие к продавцу, проверка при получении | гарантия OLX: возврат денег, если посылку не получил или товар не тот |

Сайт оформляет **только Нову Пошту**. «Безпечна угода» технически возможна только на OLX: сайт ведёт покупателя на нужное объявление.

## Где покупатель делает выбор

### В карточке товара

- Основная кнопка **«Купити»** добавляет товар в корзину (дальше — Нова Пошта).
- Вторая кнопка **«Купити з Безпечною угодою OLX»** открывает объявление этого товара на OLX в новой вкладке. Под ней подпись: «Оплата через OLX, гроші отримує продавець лише після того, як ви заберете посилку».
- Если у товара нет объявления на OLX (`olxUrl` пустой), вторую кнопку не показываем.
- Выбранный размер переносится и туда, и туда: в корзину и в подсказку «Напишіть продавцю на OLX розмір 42».

### В корзине

Перед оформлением — переключатель **«Як купуємо?»**:

1. **Нова Пошта** (по умолчанию) — форма заказа ниже.
2. **Безпечна угода OLX** — вместо формы список товаров корзины, у каждого кнопка «Купити на OLX» и размер. Если у какого-то товара нет объявления, он помечен «Доступно тільки з доставкою Новою Поштою».

## Сценарий «Нова Пошта»

### Форма

1. **Покупець:** прізвище, ім'я (Нова Пошта требует оба для получения), телефон `+380…`. Для вошедших — подставляется из профиля; гостевая покупка без регистрации остаётся.
2. **Доставка:**
   - місто — поле с подсказками;
   - спосіб: **відділення / поштомат / кур'єр** (какие оставить — вопрос к клиенту);
   - номер відділення або поштомата, или адрес для курьера.
3. **Оплата** (варианты — вопрос к клиенту):
   - **післяплата** — оплата при получении на Новій Пошті; НП берёт свою комиссию за перевод денег;
   - **передоплата на картку** — реквизиты продавец присылает после подтверждения, позже — онлайн-оплата;
   - возможна **часткова передоплата** (например, 200 грн), чтобы покрыть доставку при отказе.
4. **Коментар** (необязательно) и галочка «Не телефонуйте, підтвердіть у Viber / Telegram».
5. **Підсумок:** товары, размеры, сумма; строка «Доставка — за тарифами Нової Пошти, оплачує отримувач» (или бесплатно от суммы X — вопрос к клиенту).

### После нажатия «Оформити замовлення»

- Экран «Дякуємо! Замовлення № BD-1024 прийнято»: что будет дальше — «Ми зв'яжемося з вами протягом N годин, щоб підтвердити наявність і розмір».
- Вошедший покупатель видит заказ в личном кабинете со статусом.

### Статусы заказа

| Статус | Кто меняет | Что видит покупатель |
|---|---|---|
| **Нове** | создаётся сайтом | «Очікує підтвердження» |
| **Підтверджено** | продавец после звонка/сообщения | «Готуємо до відправки» |
| **Очікує оплату** | продавец, если выбрана предоплата | реквизиты / кнопка оплаты |
| **Відправлено** | продавец вводит номер ТТН | номер ТТН и ссылка на отслеживание НП |
| **Отримано** | продавец (позже — автоматически по данным НП) | «Замовлення отримано» |
| **Скасовано / Повернення** | продавец | причина |

## Что делает продавец (админка → новая вкладка «Замовлення»)

1. Видит новые заказы: товары, размеры, контакты, город и отделение, способ оплаты.
2. Связывается с покупателем, подтверждает → «Підтверджено».
3. **Сразу снимает этот товар/размер с OLX**, если он там висит: иначе его могут купить дважды. Админка показывает напоминание со ссылкой на объявление.
4. Создаёт ТТН в кабинете Нової Пошти, вставляет номер в заказ → «Відправлено».
5. После получения → «Отримано». Если покупатель не забрал — «Повернення».

Покупки через «Безпечну угоду» продавец видит в кабинете OLX. Чтобы остатки на сайте не расходились, он отмечает такой товар проданным в админке.

## Как это будет в прототипе (сейчас) и на сервере (потом)

| Часть | Прототип (демо в браузере) | На сервере Railway |
|---|---|---|
| Города и отделения | небольшой демо-список с подсказками | справочник Нової Пошти через её API (ключ бесплатный, выдаётся в бизнес-кабинете НП) |
| Заказ | сохраняется в `localStorage` этого браузера | база данных; продавцу приходит уведомление (Telegram/почта) |
| Вкладка «Замовлення» в админке | видит заказы, оформленные в этом же браузере | все заказы магазина |
| ТТН и отслеживание | номер вводится вручную, ссылка на сайт НП | создание ТТН и статусы через API НП |
| Предоплата | экран-заглушка | платёжный сервис |
| Кнопка OLX | ведёт на объявление, если у товара есть ссылка; у демо-товаров ссылок нет — показываем пояснение | то же; при наличии OLX API — проверка, что объявление ещё активно |

Решение, которое нужно принять для прототипа: сейчас гостевая покупка **намеренно ничего личного не сохраняет**. Чтобы демо-заказ гостя появился во вкладке «Замовлення», придётся сохранять в браузере его имя, телефон и отделение. Варианты: сохранять и честно написать об этом в форме, или показывать в админке только заказы вошедших покупателей.

## Решения клиента (2026-10-28)

1. **Оплата:** післяплата (наложенный платёж) и предоплата на карту по реквизитам. Частичной предоплаты нет.
2. **Доставку оплачивает получатель.** Бесплатной доставки нет.
3. **Способы доставки:** відділення и поштомат. Курьера нет.
4. **Все товары есть на OLX с Безпечною угодою** — кнопка OLX показывается у каждого товара.
5. **Подтверждение заказа:** через Viber или Telegram — покупатель выбирает в форме.
6. **Обмен и возврат:** условия клиент сообщит позже.
7. **Продавец — частное лицо.**

**Данные гостя:** профиль без регистрации не создаётся, но данные для отправки (ФИО, телефон, город, отделение/поштомат) сохраняются внутри заказа — продавцу они нужны для отправки. В админке видны **все** заказы сайта: и гостей, и зарегистрированных покупателей.

## Что ещё не решено

- Условия обмена размера и возврата.
- Как частному лицу принимать предоплату на карту и что с налогами — уточнить у бухгалтера (см. закон о налогообложении доходов с цифровых платформ).
- Куда приходят уведомления о новых заказах (Telegram-бот, почта) — появится вместе с сервером.
